# Zolotaya — квіти та декор

Сайт флориста-декоратора: каталог робіт із фото та категоріями
і онлайн-заявки на оформлення подій (весілля, оформлення закладів,
Гелловін, Новий рік).

## Проблема

Клієнти пишуть флористу в месенджери та Instagram, заявки губляться,
а ціну і деталі треба узгоджувати вручну. Сайт збирає заявки
в одному місці та показує роботи.

## Що вміє сайт
- Каталог робіт із фото, категорії та фільтр за категорією.
- Форма заявки з перевіркою даних (ім'я, телефон, тип події, дата, побажання).
- Адмін-панель: додавання робіт, перегляд заявок, зміна статусів.
- Адаптивний дизайн для телефона й комп'ютера.

## Технології

Python 3.14, Django 6.1, SQLite, Pillow.

## Запуск

1. Створити та ввімкнути віртуальне середовище:

       python -m venv venv
       .\venv\Scripts\Activate.ps1

2. Встановити залежності:

       pip install -r requirements.txt

3. Застосувати міграції:

       python manage.py migrate

4. Створити адміністратора:

       python manage.py createsuperuser

5. Запустити сервер:

       python manage.py runserver

Сайт: http://127.0.0.1:8000/
Адмінка: http://127.0.0.1:8000/admin/
